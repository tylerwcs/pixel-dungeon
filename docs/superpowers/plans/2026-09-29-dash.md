# Dash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dash (speed burst) to Pixel Dungeon Chase: collector any time with an 8 s cooldown, each pursuer once per round, triggered by gamepad face buttons or a keyboard key, used by AI players too.

**Architecture:** Dash state lives on each actor in the pure engine (`dist/engine.mjs`) and is advanced inside `step()` on the fixed 1/60 s timestep. Input code only sets `actor.dashRequested`; the engine decides whether a dash starts. The HUD reads a pure `dashStatus(actor)` from `dist/labels.mjs`; `dist/app.mjs` draws a trail after the renderer.

**Tech Stack:** Framework-free browser ES modules, Node's built-in `node:test` (`npm test`), Playwright (`npm run test:browser`).

**Spec:** `docs/superpowers/specs/2026-09-29-dash-design.md`

## Global Constraints

- Dash: `+60%` speed (`×1.6`) for `1.5 s`. Collector cooldown `8 s`, starting when the dash ends. Pursuers: `1` dash per round.
- No dashing during the countdown; a request then is dropped, not queued. Dash state resets in `newRound`.
- Gamepad trigger: buttons `0–3`. Keyboard: `Q` (WASD player); `/` (arrow-keys player). Edge-triggered.
- AI collector: dash when any pursuer is within `3` tiles (Manhattan, rounded positions). AI pursuer: dash when within `5` tiles of the collector along a straight wall-free row or column.
- Deterministic: no `Math.random`, fixed 1/60 s step. Character artwork never affects collision or gameplay.
- Browser code loads no framework; no new dependencies.
- `engine.mjs` and `labels.mjs` stay untagged (they have never had `?v=` tags and every `.mjs` is served `no-cache`). Bump `app.mjs`, `input.mjs` and `style.css` tags to `dash-1`. `render.mjs` is not changed.

```js
export function step(state,dt){
  if(state.phase==='countdown'){for(const a of state.actors)a.dashRequested=false;state.countdown=Math.max(0,state.countdown-dt);if(state.countdown===0)state.phase='playing';return [];}
  if(state.phase!=='playing')return [];
  state.elapsed+=dt;const prev=state.actors.map(position),events=[];
  for(const a of state.actors){if(a.dashRequested&&dashReady(a)){a.dashTime=DASH_TIME;if(!a.collector)a.dashesLeft--;events.push('dash');}a.dashRequested=false;}
  for(const a of state.actors)move(a,dt,state);
  for(const a of state.actors){if(a.dashTime>0){a.dashTime=tick(a.dashTime,dt);if(a.dashTime===0&&a.collector)a.dashCooldown=DASH_COOLDOWN;}else if(a.dashCooldown>0)a.dashCooldown=tick(a.dashCooldown,dt);}
  const c=state.actors[state.collector],cp=position(c);
  const catchers=state.actors.filter((a,i)=>!a.collector&&sweptContact(prev[state.collector],cp,prev[i],position(a))).map(a=>a.id);
  if(catchers.length){state.catchers=catchers;state.phase='result';state.winner='pursuers';return [...events,'caught'];}
  const x=Math.round(cp.x),y=Math.round(cp.y);
  if(Math.abs(cp.x-x)<.22&&Math.abs(cp.y-y)<.22&&state.coins.delete(key(x,y))){state.collected++;events.push('coin');}
  if(state.coins.size===0){state.phase='result';state.winner='collector';events.push('win');}return events;
}
```
